# Security and architecture audit, September 2026

Audited state: `dfe9e59` on `main`, 2026-09-05. Statuses are current as of
2026-09-07 and name the pull request that closed each item, so this file can be
read against `git log` rather than trusted.

One of six repositories audited in the same pass. This one has the smallest
attack surface (one public function, everything else client-side), and one
finding that matters because the function spends money.

## Method

One read-only reviewer per repository, in parallel, no paid or external calls.
This repository's reviewer broke `historyStore` with six corrupted documents
rather than reasoning about which shapes it would tolerate. On top of that,
one deterministic check across all six: no `.env` tracked at any point in
history, `.gitignore` covering it, zero secret patterns, zero
`pull_request_target`.

Every HIGH finding was verified in the code before it was written down.

## Medium and low

- [x] `historyStore.migrateHistory` validated arrays but not their elements; three corrupted documents froze the landing page. Element-level sanitisers mirroring `sanitizeProfile`; 7 tests, all red without the fix. PR #22.
- [x] `ErrorBoundary` wrapped only `/training`; `/`, `/progress` and `/profiles` showed a blank page on a render error. Boundary on every route. PR #22.
- [x] `err.message` from the Anthropic SDK was returned to the anonymous caller, which distinguishes an invalid key from a nonexistent model: free reconnaissance. Now `{ error: 'coaching_failed' }` only. PR #22.
- [ ] `.github/instructions/*.instructions.md` has a literal `*` in the file name; `git clone` fails on Windows.
- [ ] `npm audit fix` without `--force` closes `react-router` (RSC-only, not reachable here, but it removes noise). Do not run `--force`: it proposes a two-major downgrade of `@vercel/node`.
- [ ] `selectors.ts` and `BoxingEngine.ts` have no tests; `gamification/index.ts` is a dead barrel.
- [ ] `vercel.json` sets `X-Content-Type-Options`, `Referrer-Policy`, `X-Frame-Options` and `Permissions-Policy`, but no `Strict-Transport-Security` and no `Content-Security-Policy`. Add HSTS; add CSP as `Report-Only` first (the MediaPipe WASM from jsDelivr and the model from Google Cloud Storage need explicit sources).

## What holds up

- Secret hygiene is clean in the tree and the history.
- The engine is genuinely pure (no React, no I/O, no i18n), verified by import
  graph, which is why its fixture-based tests are fast and stable.
- `/api/coach` validates in a fixed order (method, origin, API key, body) with a
  hard cap on every caller-controlled field, never logs the body, and the tests
  pin all of it.
- Graceful degradation is real: without the API key or offline, training keeps
  working and the coach falls back to friendly copy.
- Video never leaves the browser; only aggregate metrics reach the backend.
